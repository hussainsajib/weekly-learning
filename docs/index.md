# Engineering Learning Hub — 2026

A 29-week structured learning plan to level up from mid-level to senior/staff engineer.
One topic per week. Each study guide is designed for approximately **2 hours of focused reading**.

## How to Use This Site

- **Read online** — use the left navigation or the tabs above to jump to any week
- **Print** — use your browser's print function (`Ctrl+P` / `Cmd+P`) on any week page for a clean printout
- **Search** — use the search bar to find concepts across all weeks
